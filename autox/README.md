# 猫眼 AutoX 手机端

正式导出使用build_wechat_script，启用USER_PRESELECTED、SUBMIT_TO_PAYMENT及OPEN_WECHAT_PAYMENT。模板本身保持锁定，运行时由本机配置生成脚本，不上传个人生成文件。

1. 工作台保存并选中猫眼目标，配置正确演出城市、日期、开售时间及唯一观演人。
2. 手机登录猫眼、提前选好场次票档与1张票，开启AutoX无障碍。
3. 连接已授权USB，点击“打开 AutoX 到微信付款页脚本（不付款）”，文件传到手机下载目录autox-maoyan-live.js。可提前传送；正式运行在开售前10分钟至开售后20分钟窗口内。
4. 手机选运行脚本，20秒内切回目标页面，保持解锁和前台。脚本等待开售按钮可用后推进。
5. 核对目标、1张及唯一指定观演人后单次提交。确认购票页的“立即支付”用于推进订单。若出现“支付订单”底部弹窗，仅从弹窗内部核对金额、唯一已选微信方式及可用按钮后，自动点击猫眼的“确认支付”唤起微信一次；不核对通过则停止。进入微信即停止，由使用者决定最后付款。其他收银台仍需要明确微信跳转按钮或明确选中微信。

票档来源由工作台明确选择。工作台填写模式使用配置票档；手机预选模式先运行只读记录脚本，保存唯一明确选中的场次、票档和1张数量。正式启动先加载本演出24小时内的记录，缺失、过期或资料变化时购票前停止。进入票档页后保留目标预选，丢失时补选同一目标；订单及支付金额必须与固定目标一致。读取不到明确选中状态时，改用工作台填写并保存目标。金额不明确、验证、目标变化、未知布局或自动扣款选项交给使用者。提交或微信唤起不明确不会重复操作，不对微信发送点击、输入或手势。

首击使用press(x,y,1)，保留新页面、唯一启用候选与范围核对。1ms是触摸参数，不是全流程时延。首击后丢弃快照并读取下一页，减少无必要字段读取和重复匹配；开售最后3秒及入口等待采用20ms观察周期，扣除读取耗时。

同时识别“前方拥堵”和“请刷新重试”、匹配目标及唯一刷新控件时自动刷新。触摸起点至少间隔400ms，仅原开售后20分钟窗口内，最多3000次；页面变化重新检查，不重复提交订单或点击底层支付。

工作台另提供选票档演练（不确认不下单）和拥堵只读检查（不点击），只读与演练不占用正式尝试锁。正式脚本在AutoX私有目录保存单次尝试标记，出现不确定结果须先核对猫眼订单。

工作台“手机按钮测速（不操作购票）”入口传送tools/autox_first_click_benchmark.js的独立测试文件。手机点运行后保持AutoX自带测试页前台约20秒，不切到猫眼；成功显示Complete:24 local trials，结果在手机下载目录qiangpiao-first-click-benchmark.json。测试仅测本地按钮启用至触摸回调，不操作猫眼或微信，也不占用正式尝试锁。正式开售时不运行测速，结果不是实际抢票总用时。详见docs/优化验收-20261012.md和docs/协作者改动复核-20261012.md。

尚未完成真实开售、创建订单及微信SDK跳转的整条真机验收；局部测速和离线测试不能保证抢票概率或最快。更新工作台后须重新传送正式脚本，避免运行手机历史旧文件。


记录按钮和详细操作见[预选恢复说明](../docs/预选恢复说明-20261012.md)。改选后重新记录，更新后重新传送手机脚本。

星号姓名兼容仅用于用户已预选、实名区域唯一且已勾选的观演人，显示掩码必须与本机保存姓名的掩码摘要匹配。导出不包含可读姓名片段；未勾选掩码、全星号、多个候选或提交前状态变化会停止。普通完整姓名仍须匹配指定观演人，未选时可补勾一次。

入口热轮询一次新读取同时复制身份与验证文本、真实入口的范围和可用状态，省去发现候选后的额外整页读取；开售前开始读取的快照不得用于开售后的点击。运行结果分别记录入口读取、发现至点击、触摸调用及点击至下一页识别耗时。发现至点击不含发现之前的读屏时间，所有指标均不代表毫秒内抢到票。

短触摸现扩展到已核对的场次、票档、确认、观演人补勾、单次订单提交以及猫眼微信网关。短触摸不可用时使用普通click；若一次短触摸返回失败，则停止，禁止改用click或再次press补点。拥堵刷新间隔仍至少400ms，微信最终付款仍不发送动作。每步触摸调用耗时记录在touchTimings；1ms仅是触摸参数，各页面转换的真实延迟仍待真机测量。

启动预检兼容同一目标页面从“已预约”变为唯一购票入口的状态，开售前不触摸。正常入口最多触摸3次：只有新读取仍确认同一详情页、唯一可用入口且无加载或验证提示时重试，触摸起点至少间隔250ms；进入选票或订单页立即结束入口重试。结果新增entryTouchCount。固定坐标实验不作为工作台默认流程，旧实验启动器已停用；使用前重新传送正常脚本。详见[入口切换修复](../docs/入口切换修复-20261012.md)和[交接说明](../docs/交接说明-20261012.md)。
