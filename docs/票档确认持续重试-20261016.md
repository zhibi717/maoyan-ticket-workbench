# 票档确认持续重试

用户要求选档后无页面反馈时继续按右下角。默认正式流程已从单次确认改为同一票档页持续确认。首次确认后的原8秒窗口保留，取消原3次上限；触摸起点最小间隔80ms，实际间隔包含页面读取、核对与按压耗时，不能保证每80ms执行一次。

只点击一次日期/票档后进入确认重试，不重复点票档。每次重试取得新页面及控件坐标，核对目标日期、金额、1张、唯一可用确认控件。等待期间短暂加载会暂停，恢复同一可操作票档页后继续；识别到订单页立即切换订单逻辑，不把票档确认的坐标点击带入订单或支付弹窗。明确缺货、请求失败或验证会报告停止。订单提交保持一次，支付停止位置保持所选模式。

默认参数位于`autox/maoyan_live_template.js`：`ENABLE_SAME_PAGE_CONFIRM_RETRY=true`，`SKU_CONFIRM_RETRY_MS=80`，`MAX_SKU_CONFIRM_TOUCHES=null`，`SKU_CONFIRM_OBSERVE_MS=8000`。参数表示尝试调度，不代表平台处理时延或成功保证。结果的`skuConfirmRetry`记录策略、实际点击次数、窗口和停止原因；触摸时序记录上限扩至128条，以覆盖这一窗口内的重试。

旧单击模板保存在`autox/versions/maoyan_live_before_continuous_confirm_20261016.js`。10月16日13:00李荣浩480元实战原脚本与结果继续保留，新模板不能改变该轮既有证据。
