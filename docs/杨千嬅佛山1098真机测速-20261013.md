# 杨千嬅佛山站 1098 元真机测速

用户授权按原来的步骤演示到猫眼支付弹窗。目标为 2026-11-21 19:00，内场1098元，1张，沿用原观演人。测试平台是安卓猫眼 App，脚本在手机 AutoX 内运行。没有实际付款。

## 首次进入新页面时发现的问题

第一次进入选票页后，“内场1098元”和“¥1098”两个文字节点被误算为两个候选，程序未选档，也未提交订单。两个节点实际上属于同一个可点击父控件。

主模板现在按相同的可点击父控件合并同一票档内重复的金额文字，并优先使用带票档类型的文字。不同可点击卡片不会合并；相同金额的其他类型票档仍会排除。新增测试覆盖同卡双标签、不同票档类型，以及原来的不同卡片重复价格保护。

这轮先在详情页核对演出和唯一日期。选票页布局是在脚本第一次进入时发现的，第二轮使用本次适配后的脚本现场读取控件；这不能视为完全未知页面的一次成功率测试。

## 修复后的第二轮结果

运行标识：`miriam-1098-payment-1791892248`。程序自动完成购票入口、1098 元票档、票档确认、订单页一次“立即支付”，并识别到金额为 1098.00 元的支付订单弹窗，状态为 `pending_payment_sheet`。该订单尚未付款。弹窗“确认支付”没有点击。

因为只有一个场次，程序沿用唯一日期，省掉重复日期点击。票档、票档确认和订单提交使用 `ACTION_CLICK`；入口使用基于当前控件坐标的 AutoX 短按。
