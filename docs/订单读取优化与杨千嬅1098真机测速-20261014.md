# 订单读取优化与杨千嬅1098真机测速

2026年10月14日，安卓猫眼 App，杨千嬅佛山站2026年11月21日19:00，内场1098元，1张，沿用用户原观演人。本轮经用户确认按完整流程测试，已到商户“支付订单”弹窗；没有点击“确认支付”，没有付款。

## 修改与保留版本

当前通用源文件为 `autox/maoyan_live_template.js`。上一版完整保存在 `autox/versions/maoyan_live_before_order_compact_20261014.js`，目标信息和运行开关保持锁定；该备份不包含实名资料。

进入订单页时，新版在本次取得的 Android 节点树上查找“实名观演人”标记。标记命中后，同一轮读取就取得完整订单文字、相关位置、按钮状态及观演人勾选状态，随后复用这份刚完成的读取，省去另一次重复获取节点树。没有命中或查询不可用时，保留普通读取作为后备。

订单专用读取减少无文字布局框的坐标读取，减少与订单决策无关的 clickable/selected 字段读取。所有文字与描述仍用于检查演出、日期、价格、数量、验证提示及异常页面。提交前仍独立取得一份新订单信息并核对观演人；提交只尝试一次。支付弹窗继续使用完整读取并核对金额后停止。

每次读取新增 `rootReadMs`、`nativeProbeMs`、`treeCopyMs`，分别记录取根节点、原生标记查询、其余遍历与字段访问的时间。最后一项包括原生调用、复制和回收，不等同于纯 JavaScript CPU 时间。

## 订单页读取仍存在的耗时

本轮首次完整订单读取共97个节点，耗时338ms：取根节点15ms，原生标记查询12ms，遍历与字段访问311ms。随后保留的提交前新读取耗时63ms。提交前完整订单读取共2次，模拟对照确认旧路径为3次。

从首次订单读取开始到提交点击开始是435ms；其中识别订单后的88ms只是最后一部分。没有记录屏幕首帧出现的时间，因此不能把88ms解释成肉眼看到订单页至点击的全部停留，也不能把435ms全部解释成屏幕已显示后的等待。

本轮入口、选档确认、提交等操作调用本身分别为6ms、11ms、19ms。这些数值只是 Android 调用返回时间，不是页面跳转完成时间。
