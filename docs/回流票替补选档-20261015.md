# 回流票替补选档

工作台的演出资料新增“回流票：目标档缺货时改选其他可售票档（不限价格）”开关。旧资料默认关闭，原定档流程保持不变。需要回流替补时开启、保存，再重新传送手机脚本；已经在手机中的旧脚本不会自动更新。

开启后的规则：

- 仍优先选择原目标票档。仅当该档不可售、不可用或没有出现时，才寻找替补。
- 按价格从低到高寻找当前选票区域内可点击、可用且没有缺货、预约或未开售标记的票档。允许高于原目标票价；相同价格有多个无法区分的票档时跳过，继续寻找可唯一识别的候选。
- 只在原定日期已经选中或页面仅有原定日期时使用替补，不切换其他场次，不把优惠金额、合计或说明文字当成票档。
- 点击前重新读取页面；候选已缺货、变动或不可用时停止，不盲点、不在提交后改买其他档。
- 切换后，选档合计、1张数量、订单及付款弹窗均按实际选中金额核对。记录同时保留原目标金额、实际金额和是否使用替补；电脑保存的原目标不会被运行时换档覆盖。
- 选档演练仍只选择票档，不点击确认或创建订单。正式流程的单次提交、验证处理与付款停止位置不变。

这是选票页的替补能力，没有增加持续刷票、自动滚动搜索或延长运行窗口。仍从目标演出详情页启动；全部不可售或读取不明确时会停止。
