# 优化验收记录

2026-10-11手机AutoX本地按钮24次对照均收到点击回调，每组合6次，20ms观察周期。全树+click从启用至回调中位179ms（172–191），全树+press(1ms)中位38ms（25–52），同读取方法减少141ms；触摸调用中位157.5→16ms。原生文本+短按回调中位27.5ms（22–35），因检查字段不同未直接替换正式全页识别。另一次18次测量单独保留在本机，不上传个人诊断文件。

这是本地测试界面，不是猫眼开售或订单至微信时延。真实页面读取样本曾有76–614ms波动；库存、网络、排队与验证仍影响结果，不能保证90%或绝对最快。

本次同步新增手机预选直达、首击短按、拥堵刷新、订单单次提交与微信后停止、接受实际预选票价、解除电脑传送按钮时间限制，以及对应测试。146项离线测试通过；同步仓库独立验证结果以合并请求为准。

测速界面重复inflate和大写按钮文字匹配问题已修复。AutoX无障碍关闭时测试停止，开启后24次成功。正式脚本与测速UI独立。

参考：[AutoX触摸文档](https://autox-community.github.io/AutoX_Docs/coordinatesBasedAutomation.html)和[Pactum7入口实现](https://github.com/Pactum7/ticket-grabbing/blob/main/MaoYan/MaoYanGoNew.js)。未移植其固定坐标持续确认和支付连点。
