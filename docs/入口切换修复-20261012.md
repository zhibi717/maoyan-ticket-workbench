# 开售入口切换与有限重试（2026-10-12）

旧固定坐标实验在开售前最后检查仍要求“已预约”，遇到正常购票入口切换会在触摸前退出。普通工作台模式的启动检查随后也发现残留相同条件，已一并修正；同一目标的启动预检接受预约状态或唯一购票入口，实际触摸仍等待开售。

正常入口点击后，重新读取确认仍在同一演出详情页、没有加载或验证提示且唯一入口可用时，可有限重试。最多 3 次，触摸起点至少间隔 250 毫秒；选票或订单页出现后立即结束入口重试。结果文件新增 `entryTouchCount`，入口时刻保留首次触摸，触摸明细用于区分“未触摸”和“触摸后未跳页”。

不得将此规则扩大成连续点击订单提交、支付或整个屏幕右下角。票档缺失时仍需明确选中配置票档；金额、日期、观演人及支付弹窗检查保留。

离线回归覆盖预约入口在启动前或临近开售时切换、首次入口触摸未跳页、已进选票页停止入口重试、触摸返回失败不补点、错误城市与验证提示阻止动作。真机完整流程及延迟仍待验证。使用前重新传送手机脚本。
