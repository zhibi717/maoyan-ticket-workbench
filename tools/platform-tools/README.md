# Android Platform Tools

本机已从原项目迁入 adb.exe、AdbWinApi.dll、AdbWinUsbApi.dll 以及随包存在的 NOTICE / source.properties。
这些工具仅用于 USB 模式，离线模拟不启动 adb。

在其他电脑部署时，从 Google 官方下载 Windows Platform Tools 并解压到本目录：
https://developer.android.com/tools/releases/platform-tools

不要从不明抢票脚本压缩包获取 ADB。此目录二进制不纳入 Git；保留上游 NOTICE。
